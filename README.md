# Shengjia Luo - Portfolio and Research

This repository contains my personal portfolio website and selected research projects in consumer insight, social listening, and cross-national analysis.

## Website

[Open the portfolio website](https://1111jia.github.io/SLuo_Profile/)

The site uses plain HTML, CSS, and JavaScript. Everyday text, links, and image paths are maintained in [`content.js`](content.js). Portrait and personal-photo spaces currently use clean placeholders and can be filled later without changing the layout. Resume buttons remain disabled until a final public resume is added.

## Research projects

- [Gender Differences in Pro-Environmental Behaviour](research/cross-national-environmental-behaviour/) - a 13-country multilevel analysis using ISSP data and the UNDP Gender Inequality Index.
- [Organic Food Attitudes in German Reddit Discussions](research/reddit-organic-food-research/) - a social-listening study of 1,827 comments collected from 2019 to 2022.

Each project includes a recruiter-facing README, three redesigned figures, a PDF report, analysis source, and a data-provenance note.
